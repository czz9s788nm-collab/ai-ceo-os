# Contributing

Thank you for helping improve AI CEO OS.

1. Open an issue describing the problem or proposed change.
2. Keep pull requests focused and avoid committing real business or personal data.
3. Run `npm test` and `npm run check` before submitting.
4. Add or update tests for behavior changes.
5. Confirm that new assets and dependencies can be redistributed under the MIT license.

By contributing, you agree that your contribution may be distributed under this
project's MIT license.
